# Doctor Triage Portal (`frontend-doctor`)

## Purpose
Specialized desktop web portal for ophthalmologists at secondary or tertiary eye care hospitals to review referred cases.

## Key Features
- Priority triage queue (sorted by AI-predicted DR severity level 0–4 and urgent pathology flags).
- Synchronized multi-modal inspection: raw fundus photograph, lesion segmentation overlays, and Grad-CAM explainability heatmaps.
- Diagnostic audit log with one-click referral authorization.
